The Fix log index at `/fix-log/` has a markdown version at `/fix-log.md`. The page's HTTP Link header pointed to it. Its HTML head did not. The head held one alternate link, to the writing RSS feed, and no `text/markdown` alternate.

Every other section page names its markdown copy in the head. That includes the homepage, Writing, Projects, About, the changelog and each single fix entry. An agent or feed tool that reads the head, not the HTTP headers, never learned that `/fix-log.md` existed. It would find a machine-readable copy on every section page but this one.

The page template in `src/pages/fix-log/index.astro` did not pass the markdown address to the shared layout. Single fix pages already did. The fix adds `markdownAlternate="/fix-log.md"` to that template, and the layout writes the tag.

The head of `/fix-log/` now carries `<link rel="alternate" type="text/markdown" href="https://www.mattpyle.com/fix-log.md">`, the same tag as the other section pages.
