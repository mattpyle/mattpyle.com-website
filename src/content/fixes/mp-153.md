The Fix log index at `/fix-log/` had a markdown version at `/fix-log.md`. Its HTML head did not name it. The head held one alternate link, to the writing RSS feed. Every other section page checked carried a `text/markdown` alternate link, including each fix entry page.

An agent or feed tool that read the page head never learned the markdown version existed.

The change passed the markdown address to the page layout in `src/pages/fix-log/index.astro`. Fix entry pages already did the same. The layout then wrote the alternate link into the head.

After the change, the head of `/fix-log/` carried `<link rel="alternate" type="text/markdown" href="https://www.mattpyle.com/fix-log.md">`, like the other section pages.
