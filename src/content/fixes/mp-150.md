The site hands agents a list of its pages in two places: `/webmcp/index.json` and the answers of its A2A agent. That list named WebMCP, Steward and Audit as pages beyond the nav. It left out the Fix log, which llms.txt lists under Pages. The index held no mention of `fix-log` at all.

This let down an agent asked to summarise the site and what it has fixed. Such an agent works from these machine-readable files, not the HTML. Asked to list the pages, the A2A agent named seven sections and three extra pages, but not the Fix log. Asked "What is the fix log?", it answered with changelog entries instead of the 78-entry Fix log.

Both surfaces read one list, `sitePages()` in `src/data/site-sections.mjs`. That list was not updated when the Fix log was added to the site. The fix adds the Fix log to it, with the same summary llms.txt uses. A test now expects the Fix log in the agent's page list.

The index at `/webmcp/index.json` now contains `https://www.mattpyle.com/fix-log/`. The A2A agent's page list is built from the same source and now includes the Fix log.
