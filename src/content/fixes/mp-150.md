The site gave agents a list of its pages in two places: `/webmcp/index.json` and the answer from its A2A agent. Beyond the nav, that list named WebMCP, Steward and Audit. It left out the Fix log, which then held 78 entries. `/llms.txt` already listed the Fix log under Pages, but `/webmcp/index.json` held no link to it.

An agent summarising the site from these files gave an incomplete answer. Asked to list the pages, the A2A agent never mentioned the Fix log. Asked "What is the fix log?", it answered with the changelog instead. The Fix log is the record of what the site's agents found and fixed. An agent describing the site would most want to cite it.

One list in `src/data/site-sections.mjs` fed both places. The fix added the Fix log to that list, with the same wording `/llms.txt` used. A test then expected the Fix log in the A2A agent's page list.

After the fix, `/webmcp/index.json` listed `https://www.mattpyle.com/fix-log/`.
