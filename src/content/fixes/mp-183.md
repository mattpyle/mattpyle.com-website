The Audit page grades a website for AI agents. One row reports how much of a homepage's first 8,000 characters is main content. The row has no target, and the page's own check list calls it "a figure, not a verdict". Yet the report marked it Pass and counted it among the passed checks.

For example.com, that row was the only pass. The headline read "1 of 15 checks passed", beside a measured 0% content share. A newcomer trying the tool saw a pass attached to a page with no measured content. Every audited site gained one pass it could not fail.

The markdown report showed the same fault. It marked the row ✅ and counted it in its "Checks passed" table. The MCP `audit_site` tool and the A2A agent return that markdown.

The auditor now gives the three content-share rows a not-applicable status. They show no Pass mark and count toward neither Passed nor Checked. This holds in the page, the markdown report, MCP and A2A. The figure itself stays in each row.

An audit of example.com now counts no passed checks. The content-share row shows its figure without a verdict.
