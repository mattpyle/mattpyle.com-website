The /audit report for example.com read "1 of 15 checks passed". Its one pass was the row "The homepage's first 8,000 characters are measured for content share". That row showed Pass beside a measured 0% content share. The markdown report gave it a ✅ and counted it under Content access. Yet the same page's check list describes the row as "A figure, not a verdict".

This let down a newcomer trying the tool on a site. They want to understand the result at a glance, and the headline is the number they keep. A row that could never fail added one to every site's score. Here it put Pass on a reading that meant the opposite. Agents calling the audit over MCP or A2A received the same passed status.

The auditor now gives the three content-share rows the status `not-applicable` instead of `pass`. They count toward neither Passed nor Checked. This holds in the HTML report, the markdown report, MCP and A2A. Each row still reports its figure.

On production, the content-share rows show their figure with no Pass mark. They no longer add a pass to any site's score, so example.com's one false pass is gone.
