The scorecard's run history showed the 3 September row as "Accessibility: 100/100 (Fail)". A perfect score carried a failing label, and the page did not say why.

The two figures came from different checks. The number was the Lighthouse score. The failure came from the axe gate, which found one violation across 25 tested pages. The row set them side by side as if one caused the other.

A visitor reading the history to judge how the site had held up saw what looked like a bug in the scorecard. The scorecard exists to be believed, so that cost trust.

The note for a failing gate now carries the gate's own description. A run that fails on axe violations shows the violation count next to the score. The archived 3 September row keeps its old wording.
