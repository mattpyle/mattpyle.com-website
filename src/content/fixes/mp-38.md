The site runs an agent at /a2a. Its example question is "What agent-readable surfaces does this site expose?". The reply listed eight surfaces.

The llms.txt file lists more. The reply left out the MCP endpoint and its discovery entry, the MCP server card, the Agent Skills index, the ARD catalogue and the two JSON feeds for the scorecard and activity.

An agent that trusted the reply never learned about the MCP endpoint. That endpoint does the same audit work as one of the agent's own skills. The site says its agent never contradicts its pages, and here the two lists had drifted apart.

The hand-written list now includes every missing surface, with the full URLs for the WebMCP files. A test fails when a URL in the llms.txt resources section is absent from the reply.
