The WebMCP post's code changed on 18, 30 and 31 October. The copyable handler began to validate its inputs. Every executeTool call moved from a JSON string to an object. The minimum Chrome version went from 149 to 155.

The post's updated field still equalled its publication date, 3 September. So the page showed no "updated" line, and the structured data, the markdown frontmatter and the sitemap all said 2026-09-03.

A returning reader who had copied the old code got no signal that it now broke. Meanwhile the accessibility post showed "updated 30 Oct" for a one-sentence tense change.

The post's updated field is now 2026-10-31. The updated line on the page, the structured data, the markdown frontmatter and the sitemap all follow from it.
