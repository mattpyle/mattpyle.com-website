The A2A endpoint accepts the older message/send spelling as an alias. Both agents.md and the site's Agent Skill said replies to it "only ever use the current form".

A live call showed otherwise. A message/send request gets a 0.x-shaped reply, with a kind field and a lowercase agent role. The same question sent as SendMessage gets the 1.0 shape, with ROLE_AGENT and a media type.

The behaviour was deliberate. A 1.0 reply on the 0.x path is one the caller cannot read. The docs were never updated. An agent that trusted them and looked for ROLE_AGENT found neither field.

Both docs now say the alias is answered in the 0.x dialect it was asked in, with kind fields and lowercase roles and task states. The line about tasks/get follows the same terms.
