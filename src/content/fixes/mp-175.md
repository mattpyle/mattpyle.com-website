Every page on the site carries a hint that points agents to `/llms.txt`, the site's guide for them. The hint said the file was `text/markdown`. It appeared in each page head and in the homepage's `Link` header. Production served the same file as `text/plain; charset=utf-8`.

An agent arriving on any page follows that hint before it reads the HTML. It chooses how to parse the file from the advertised and served types. Here the two disagreed. The agent got a mislabelled index from the one file every page sends it to.

The change removes `type="text/markdown"` from both hints. One is the `<link rel="describedby">` in `src/layouts/Layout.astro`, on every page. The other is the llms.txt entry of the homepage `Link` header in `vercel.json`. The llms.txt proposal puts no type on this hint. The file itself is unchanged and is served as plain text. The `agents.md` hint keeps its type, because that file is served as markdown.

Every page now points to `/llms.txt` with `rel="describedby"` and no type. The homepage header does the same. The hints no longer claim a type the server does not send.
