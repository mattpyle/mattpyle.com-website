Every page on the site points agents to `/llms.txt`, the site's guide for them. The `<link>` in each page head said the file was `text/markdown`. The homepage's `Link` header said the same. Production served the file as `text/plain; charset=utf-8`.

An agent landing on any page follows that link before it reads the HTML. It chooses a parser from the type it is promised and the type it receives. Here the two disagreed, so the agent got a mislabelled index. The file itself was the same either way.

The llms.txt proposal gives this hint no type, and its own example sets none. The change removed `type="text/markdown"` from both hints: the `<link>` in `src/layouts/Layout.astro` and the header entry in `vercel.json`. The file stays plain text. The `agents.md` hint keeps its type, because that file is served as markdown.

All seven pages checked now carry the link with no type. The homepage header names `/llms.txt` with no type. The hints no longer promise a type the server does not send.
