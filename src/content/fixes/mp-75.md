The /steward page has a table called "What one Steward request is". Its Signature row said each request is signed and "itsSignature-Agent header" names the Signature Agent Card. There was no space between the two words.

The same slip appeared in the markdown version of the page, which agents read.

The row is for site owners who have just seen the audit agent in their logs. It explains how the requests prove who sent them. A run-together word in its one technical term looks careless.

The source text ended a line with "its" and opened the next with the code element. The build dropped the line break instead of adding a space. Both words now sit on one line, and the HTML and the markdown read correctly.
