The search and share description of the "Hello, World!" post ended "The first post is the smoke test." The sentence appeared three times in the page head, in the meta, Open Graph and Twitter descriptions. The post's first sentence calls it the second published entry. The writing list puts another post, from 13 July, before it.

A newcomer from a search result or a shared link reads that description before the page. One click later, the post told them the opposite. They could not tell whether it was the first post or the second.

The fix reworded the last sentence of the post's search description in `src/content/writing/hello-world.md`. It now reads "Steward's first post is the smoke test." The description shown on the page itself never carried the sentence and did not change.

The page head no longer says this is the first post. The description it serves now agrees with the post's opening.
