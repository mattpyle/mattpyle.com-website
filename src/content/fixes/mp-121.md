The "Hello, World!" post at `/writing/hello-world/` had a search and share description that ended "The first post is the smoke test." The same sentence appeared in the page's meta description and in its Open Graph and Twitter descriptions.

The post says the opposite. Its first sentence calls it the second published entry. The writing list also places an earlier post before it. A visitor arriving from a search result or a shared link met two contradictory claims within one click. The contradiction read as a mistake, not as part of the post's joke.

The last sentence of the description now reads "Steward's first post is the smoke test." The change is in the post's front matter. The visible description on the page did not carry the sentence and is unchanged.

The old sentence no longer appears anywhere in the page's HTML. The search and share description now agrees with the post.
