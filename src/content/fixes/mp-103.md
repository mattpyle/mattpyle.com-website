Each project on /projects has its own anchor, and llms.txt links to it, for example /projects/#project-argus. The WebMCP index at /webmcp/index.json gave all three projects the bare /projects/ address. The site's agent used the same kind of list.

A search for a project through the WebMCP tools returned that bare address. Two machine surfaces disagreed on the citable address of the same project, and the WebMCP one was the less specific.

An agent summarising the site's projects wanted to cite each one. It could land a reader only at the top of a three-card list.

Each project's address in the index and in the agent's digest is now /projects/#project-<id>, matching llms.txt. The agent's projects answer links each project's title.

The index now carries the Argus anchor, and the others follow the same pattern.
