The markdown copy of the Activity page opened with a false sentence. It said the nightly scorecard audit did not appear in its numbers. The same file's client table listed that auditor first, as `steward-audit`, with 3,723 requests in 7 days. The HTML page labelled the same rows "this site's own nightly auditor".

The sentence let down agents asked how much agent traffic the site gets. The site invites them to read its pages as markdown. This page gave them a lead that contradicted its own table. An agent trusting the lead would report the site's own nightly job as outside agent interest. That share was larger than claudebot's 169 requests and oai-searchbot's 59.

The fix rewrote the lead in `src/pages/activity.md.ts`. The false clause was removed. A new sentence says the site's own nightly auditor is counted, under `steward-audit`.

After the fix, the Activity page's markdown no longer carried the old sentence. Its lead then agreed with its client table and with the HTML page.
