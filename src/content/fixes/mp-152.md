The markdown copy of /activity opened with a false claim. Its lead said "the nightly scorecard audit does not appear in these numbers". The same file's client table listed `steward-audit` first, with 3,723 requests in 7 days. The HTML page labels that row "this site's own nightly auditor".

The markdown copy is the version agents read. An agent asked how much agent traffic the site gets would trust the lead. It would then present the site's own nightly job as outside interest. That job outnumbered every outside crawler: claudebot made 169 requests and oai-searchbot made 59.

The lead in `src/pages/activity.md.ts` was reworded. It now says the site's own nightly auditor is counted, under `steward-audit`. The HTML page already said this.

The markdown at /activity no longer carries the old sentence. Its lead now agrees with its client table.
