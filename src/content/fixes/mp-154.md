An agent asked the site's A2A agent at `/a2a` what skills it has. The reply listed the site's agent surfaces, including the endpoint itself. That line read "SendMessage, and GetTask for polling a deep audit's Task." It named neither CancelTask nor consultant sessions.

The endpoint already implemented three methods. Its GET reply listed SendMessage, GetTask and CancelTask. Its error for an unknown method named all three too. An agent that trusted the A2A agent's own answer never learnt that a consultant session can be closed.

The line was written before the audit consultant arrived as a third skill on 13 November. That change updated the Agent Card, `agents.md` and `llms.txt`, but not this description. The fix rewrote the one line in `scripts/generate-a2a-digest.mjs`, which builds the agent's answers.

The reply's line about the endpoint now names CancelTask for closing a consultant session, alongside SendMessage and GetTask.
