The markdown version of /steward has a table of five facts about one audit request: the user agent, the robots.txt token, the cost, the frequency and what it collects. An agent that meets the audit crawler in its logs reads this table to decide whether to allow it.

In markdown, that table arrived as a single line of raw HTML. It held 20 tags, and each carried a build attribute. It was the only one of 13 markdown pages with build attributes in it. The converter turns only tables with a heading row into markdown. This table had row headers only, so it was copied through as HTML.

The converter now turns a table of row headers into a list. Each row reads as a bold label and its value, for example "Frequency: Once, when a person or an agent asks."

The markdown page now holds no build attributes. The same list comes back when the page is requested with an Accept header for markdown.
