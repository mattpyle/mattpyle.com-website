The card for the site's newest project was a link whose address was /projects/, the page the reader was already on. Clicking it reloaded the page at the top. Nothing marked the card as going nowhere.

The other two cards went somewhere. One led to a project page and one to the code on GitHub.

A developer who saw a live project and wanted to know how it works clicked the card. The reload read as a broken page.

The cause was a fallback. A project with no live address and no repository got a link to the Projects page. That project has neither, so the fallback applied.

The card now renders without a link when it has nowhere to go. The other two cards are unchanged.
