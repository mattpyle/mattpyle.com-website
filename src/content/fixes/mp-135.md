This site runs its own agent at /a2a, which answers questions from other AI agents. A common one is "How do I contact Matt?". The answer named GitHub and LinkedIn, then pointed to the About page.

The About page tells a different story. Its "Say hello" section lists Bluesky first, and anyone can message Matt there. An assistant working for a recruiter would repeat the agent's answer and miss the channel Matt leads with.

The cause was a shared list. The answer reused the profiles the site publishes for search engines, and that list leaves out Bluesky on purpose. The fix gives the contact answer its own list, the same channels as "Say hello". The search engine list is unchanged.

The agent now names Bluesky, GitHub and LinkedIn, in that order.
