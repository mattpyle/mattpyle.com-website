The site offers /llms-full.txt as the one-file export of everything it publishes. An agent fetches it and splits it by heading to find each post, project and changelog entry.

The outline was upside down. The file had 57 level-two headings, but only five were the export's own sections: WebMCP tools, Scorecard, Writing, Projects and Changelog. The other 52 came from inside the items. "What is WebMCP?" sat at level two, directly under the post's level-three title, so it outranked the post it belonged to. Anything that chunks the file by heading would split each title from its body.

The export now demotes every heading inside an item by two levels. "What is WebMCP?" is a level-four heading, and deeper headings go to level five. The file holds exactly five level-two headings, and the outline nests as section, then item, then item section.
