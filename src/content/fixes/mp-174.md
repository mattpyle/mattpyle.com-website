The `/steward` page, `agents.md` and the `audit_site` tool description all carried one wrong sentence. Each said "any path in the URL is ignored". The site's own consultant agent was told the same about its tool. Given a page address, the audit also measures that page. A `reading-budget-page` row reports how much of its first 8,000 characters is content.

An agent asked to check one page reads these docs before it calls the audit. Told the path was ignored, it would strip the path and audit the bare domain. It then lost the per-page measurement it had been asked for. The tool did more than its own description admitted.

The old sentence is rewritten in every place it appeared. The new wording keeps the site as the unit audited. It adds that a path names one extra page, measured in the `reading-budget-page` row.

Neither `/steward` nor `agents.md` now contains the old sentence. The `audit_site` description and its `url` inputs now say what a path does.
