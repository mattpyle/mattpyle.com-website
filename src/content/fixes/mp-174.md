The /steward page and agents.md each said "any path in the URL is ignored". The `audit_site` tool description on the MCP server said the same. Its `url` input said "Any path is ignored". Yet an audit of /writing/hello-world/ returned a `reading-budget-page` row measuring that page.

The wording misled an agent asked to check how readable one page is. Such an agent reads agents.md and `tools/list` to plan its call. Told the path is ignored, it strips the path. It then loses the per-page measurement that the reading-budget check added. The consultant model was told the same about its own tool.

The sentence predated the reading-budget check, which began using the path to name a page. The fix rewrote it on /steward and its markdown copy, and in agents.md. It also rewrote the MCP tool description, its `url` inputs and the consultant's tool. Each now says a path names one extra page. That page's first 8,000 characters are measured for content share, in the `reading-budget-page` row.

Neither /steward nor agents.md now says a path in the URL is ignored. The docs now say what a path does.
