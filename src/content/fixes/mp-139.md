The Steward page explains what the auditor checks and how to run it. It had three GitHub links: the profile in the footer, the website repository and its issue tracker. The repository link sat under Contact, as the place to file a complaint.

The page never named the agents/steward folder. That folder holds the README with the "Why Temporal" and "How it works" walkthrough of each workflow. A developer who followed the Steward card from /projects to copy the approach had to search a repository of hundreds of files.

The "What Steward is" section now has one sentence linking the agents/steward folder on GitHub.

The page now links straight to the code and its README.
