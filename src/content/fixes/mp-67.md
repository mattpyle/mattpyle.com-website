The Projects page links the mattpyle.com card to this site's repository. The README's Stack section there said "Astro 7, static output" and "no backend". The site runs ten routes that render on the server for each request.

Those routes include /mcp, /a2a, the audit page, the scorecard, the activity page and the markdown routes. The README itself went on to describe the /mcp endpoint, A2A calls and deep audits, so it contradicted itself.

A developer asking whether the setup is worth copying met a wrong architectural fact first. It also hid the most copyable part: how a mostly static site carries an MCP and an A2A endpoint.

The Stack section now says the output is mostly static and deployed on Vercel. It names the routes that run as functions on each request, and says the only server code is those routes.
