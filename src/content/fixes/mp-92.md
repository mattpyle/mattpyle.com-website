The mattpyle.com card on /projects described the site as "A static Astro 7 personal site". The same line appeared in /projects.md, llms.txt and llms-full.txt. llms-full.txt also said "static output, no client-side framework, no backend". The site's agent repeated it when asked about Matt's projects.

The site runs ten routes on the server, including /mcp, /a2a and /activity. Its newest changelog entry described a server that verifies signatures and stores counts. That is the opposite of "no backend".

A recruiter judging what Matt has built repeats the card's line. An agent that repeats it passes on a fact the site contradicts. The server routes are the part that no static site can do.

The project description and its first body line are rewritten, and so is the copy in the agent's digest.

Neither phrase appears on any of the four pages now.
