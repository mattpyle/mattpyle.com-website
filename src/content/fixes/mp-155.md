The A2A notes in `/agents.md` described the error for an unsupported method name at the `/a2a` endpoint. They said this `-32601` error named "the one method that works". That was written when the endpoint had only one method. By November 2026 it had three: SendMessage, GetTask and CancelTask. Its error said so and listed all three.

The note let down a developer calling `/a2a` by hand and reading the notes to understand an error. They could not match the error they got to the note's description. The same file listed three methods in a table eight lines above the note.

The fix changed one clause in `public/agents.md`. The note then said the error named "the methods it implements".

After the change reached production, `/agents.md` no longer contained the phrase "naming the one method that works". Its errors note matched both the method table and the error the endpoint returned.
