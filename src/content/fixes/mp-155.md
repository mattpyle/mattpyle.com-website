The A2A notes in `/agents.md` describe the error an agent gets for a wrong method name. They said an unknown method returns `-32601` "naming the one method that works". That clause dates from when the `/a2a` endpoint had one method. It now has three: SendMessage, GetTask and CancelTask.

The wording let down a developer calling `/a2a` by hand. They read the notes and then sent a request with the method `Foo`. The endpoint answered `-32601` and named all three methods it implements. The same file lists those three methods in a table eight lines above. The file contradicted itself, which gives an agent a reason to distrust the rest of it.

The fix changed one clause in `public/agents.md`. The note now says an unknown method returns `-32601` "naming the methods it implements". That wording stays true if the endpoint gains or loses a method.

The note on production now matches the error the endpoint returns and the table above it. The old phrase no longer appears in `/agents.md`.
