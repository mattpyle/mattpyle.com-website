The site registers six WebMCP tools. Four only read published content: describe_site, get_recent_writing, search_content and list_related_sites. agents.md says so, and one tool description ends "Read-only." No tool carried an annotations member in /webmcp/tools.json.

In the WebMCP specification, readOnlyHint defaults to false. A tool with no annotation is therefore exposed as not read-only. An in-browser agent deciding which calls are safe without asking the user saw all six as state-changing.

The four read tools now register with readOnlyHint set to true. The tools.json manifest passes each tool's annotations through. set_appearance and sign_guestbook stay unannotated.

The manifest now shows readOnlyHint true for the four read tools.
