The audit page is the site's "first door" for running its audit. Its markdown version at /audit.md existed and answered with the right content type. The HTTP response even carried a Link header for it.

The page's HTML head was different. Of 14 pages checked, 13 carried a link with rel="alternate" and type="text/markdown". The audit page held only the RSS alternate and a link to llms.txt. An agent that parsed the HTML for a cleaner version found nothing.

The page did not pass its markdown address to the shared layout, and the layout adds the tag only when it gets one. The fix passes /audit.md from the page.

The audit page now carries exactly one markdown alternate link in its head, the same as the other 13 pages.
