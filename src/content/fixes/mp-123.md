The About page's structured data held a Person node (Director of Growth, working for Temporal Technologies), a WebSite node and a breadcrumb trail. The homepage carries the same Person node.

Nothing marked /about as the page about that person. There was no ProfilePage or AboutPage node pointing at the Person. Someone searching for "Matt Pyle" gave a search engine no signal about which page to show.

The About page now adds one ProfilePage node at /about/#profilepage. Its mainEntity refers to the existing Person node by its identifier, so nothing is duplicated.

The structured data on /about now contains a ProfilePage whose subject is the Person.
