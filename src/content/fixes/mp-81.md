The site's Agent Skill has a table of which surface answers which question. Its row for llms-full.txt said "Every published word, in one request".

The file holds 8,921 words. That covers the posts, projects, changelog entries, the scorecard snapshot and a short WebMCP paragraph. It holds none of the About page's text, none of the agent page's body and none of the WebMCP page's body.

An agent that trusted the skill would fetch the file and answer "who is Matt" from one line of its header. It would never learn there is a page about him.

The row now says the file holds every article, project and changelog entry, which matches the file's own introduction.
