The markdown version of /steward lists the 13 checks the audit runs. Each check was one bullet, with its name, its description and its weight joined by single spaces. A line ended "...its groups and rules parse. medium".

Nothing marked where the name stopped or the description began. Nothing showed that "medium", "high" or "low" was a weight and not the last word of the sentence. Names that start with a lower-case term, such as robots.txt, made it worse. The audit page's own markdown at /audit.md showed the same checks as a table, so the two disagreed.

An agent reading the page wanted to know which checks run and how much each counts. The weight is the one fact it cannot recover from prose.

The fix puts each name in bold and each weight in the form "(weight: medium)". All 13 checks now carry a labelled weight, and no line ends in a bare "medium", "high" or "low".
