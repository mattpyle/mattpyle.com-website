The "Content structure" list in `/agents.md` maps the site's pages. It named eleven paths, from `/` to `/steward`. It did not name `/fix-log` or `/audit`. The site's `/llms.txt` lists both pages under "Pages".

The site tells agents to read `/agents.md` for how to cite it. An agent that trusted its map would not know the Fix log or the Audit form existed. It could not cite either page. The two files disagreed on which pages the site has.

The list is kept by hand. It was not updated when the Audit form shipped, nor when the Fix log followed. The fix added two lines to the list, worded as in `/llms.txt`. The `/fix-log` line says each fix has its own page at `/fix-log/<slug>`, with a markdown copy at `/fix-log/<slug>.md`. The `/audit` line describes a form that audits a site you name and shows the report in the page.

The page map in `/agents.md` now names both pages.
