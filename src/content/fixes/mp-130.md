The Main navigation landmark named its links "/writing", "/projects", "/changelog", "/scorecard" and "/about". The wide row, the narrow row and the "more" panel all did the same.

NVDA and VoiceOver speak the slash. A screen reader user moving through the navigation on any page heard "slash writing, slash projects" and so on. The slash is styling, and hearing it five times a page is noise.

The header now wraps the leading slash of each link in an element hidden from assistive technology. The link names read "writing", "projects" and so on. The visible word stays in the name, so voice control still works.

The slash still shows on screen. The text ">/writing<" no longer appears in the header markup of the homepage, /writing/ or /about/.
