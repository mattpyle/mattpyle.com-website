The list called "What the audit checks" describes 13 checks. Two descriptions name a technical term in code style: `Accept: text/markdown` and `Link`. Each surface showed them differently, and only one got them right.

On /steward/ and /audit/, the description was plain text with the backtick characters in it. A visitor saw the stray backticks, and the term did not use the monospace face the site uses for code. In steward.md, the converter escaped them, so an agent read a backslash before each backtick. That page exists to show agents clean markdown. Only /audit.md rendered the terms as code, by accident.

The fix renders the text between backticks as a code element in the HTML of both pages. The converter then turns that element into a plain code span in steward.md.

Both pages now show two code elements in the check list and no backtick characters. steward.md has no escaped backticks, and reads "with `Accept: text/markdown` returns".
