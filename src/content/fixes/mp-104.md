The accessibility post shows "updated 31 Jul 2026" to human readers. Its page data carries the same date as dateModified. The markdown copy of the post held only the publication date, 13 July 2026. The string 2026-07-31 appeared nowhere in it.

An agent that reads the markdown, as the site tells it to, checks the date to judge how current a post is. This agent saw a post last touched in July when it had been revised later. The markdown was the one surface that lost the date.

The markdown route now reads the post's updated field. When the field is set, it writes dateModified after datePublished in the frontmatter.

The markdown copy of the accessibility post now states dateModified as 2026-07-31, matching the page.
