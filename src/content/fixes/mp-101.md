When /audit refused an address, the error asked for one "starting with http or https". The form's own placeholder is example.com. The auditor adds https:// to any address without a scheme.

The advice was wrong for the commonest typo. Adding a scheme to "not a site" gives an address that still fails. The real problem, the spaces, went unmentioned.

A visitor whose address was refused wanted to know what to type instead. The error sent them to add a scheme, so the next attempt failed for the same reason.

The error now matches the placeholder. It asks only for a public website address, such as example.com. The scheme demand no longer appears.
