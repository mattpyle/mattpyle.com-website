On 20 November the post "Accessibility, AI, and testing with screen readers" gained a new paragraph. It begins "That was the July version" and explains how the filter on `/changelog` changed. Every date for the post still said it was last updated on 30 October. That date appeared in the byline, the page data, the markdown copy, the sitemap, the WebMCP index and the site's A2A agent.

A returning reader uses the updated line under the title to decide whether to read a post again. An agent asked what has changed on the site uses the same date to decide what to re-read. Both were told the post had not moved since October, so both would miss the correction.

The fix set the post's updated date to 20 November, the day the paragraph shipped. Every dated surface reads that one field, so the byline, the page data, the markdown copy, the sitemap, the WebMCP index and the A2A answer all follow it.

On production the page and its markdown copy now give 20 November 2026 as the date the post last changed.
