The WebMCP post teaches that a browser passes an agent's arguments to a tool without checking them. It promises validated tool handlers and working examples. The snippet it asked readers to copy did not validate.

Run against the same inputs as the site's real handler, the snippet returned no posts for a limit of "three". It also returned none for the tag "temporal" when a post carried "Temporal". Passing the number 5 as a tag threw a TypeError.

A developer who pasted the snippet shipped the failure the post warns about. An agent sending a string limit or a numeric tag got an empty list or an exception, with no error it could act on.

The snippet now checks the limit with Number.isInteger. It normalises both the tag argument and each post tag before comparing. It matches the handler the site ships.
