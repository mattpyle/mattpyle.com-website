An agent can ask the site's A2A endpoint what changed recently or what the projects are. It may cite or fetch the addresses in the answer. The site's own skill tells agents to link the specific page.

The answers linked pages without the trailing slash, such as /projects and /changelog. Each address answered with a 308 redirect to the slashed form. Every page's canonical link, the sitemap and llms.txt use the slashed form.

So the endpoint named an address that no other surface names. Each fetch spent a redirect, and a citation built from the answer did not match the canonical URL.

The responder now links /projects/ and /changelog/ with the slash, the last two citations that lacked it. A test checks that page addresses in both answers end in a slash.
