The site runs an agent at /a2a. Asked which agent surfaces the site exposes, it described its own endpoint as "JSON-RPC 2.0, SendMessage only".

That was wrong. A GET to /a2a lists two methods. The error for an unknown method names both. agents.md lists both. A deep audit returns a Task that only GetTask can read back.

An agent that believed the reply could not finish a deep audit. The reply also contradicted the endpoint's own error message, which gives an agent a reason to distrust the rest of what it says.

The text predated the audit skill. It now reads "JSON-RPC 2.0: SendMessage, and GetTask for polling a deep audit's Task." The change is in the script that builds the answer and in the data file it writes.
