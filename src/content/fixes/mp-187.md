The markdown copy of every fix log entry, of the About page and of the Changelog page contained a link to itself. Each of the 78 fix log entries carried `[view markdown](/fix-log/<slug>.md)`, pointing at its own file. `/about.md` ended with a link to `/about.md`. `/changelog.md` carried a link to `/changelog.md`. That made 80 of the 107 pages in the sitemap.

An agent that fetched a page's markdown to read it was offered the very file it was reading. The link led nowhere. An agent that follows links to read a site could spend a second fetch on text it already had. Posts and changelog entries had no such link, because their copies are built from the source markdown.

The converter that turns rendered pages into markdown dropped any link whose target was the page's own markdown file. It read that file from the alternate markdown link in the page's head. One rule covered the fix log rail, the About page and the Changelog page. The HTML pages kept their links, which were right for a person.

The markdown copies of all three kinds of page carried no link to themselves. Their other links stayed.
