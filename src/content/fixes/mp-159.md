The Steward page's "What Steward is" section held a sentence that pointed to the code. It read "The code is open: agents/stewardholds the workflows and a README on how they work." The markdown copy of the page had the same run-together word.

That sentence was there for developers who want to know where the auditor's code lives and how it works. At the point where the link ended and the sentence went on, they met one word: "agents/stewardholds".

The cause was in the page's source. The link closed at the end of one line, and "holds" began the next line. The build dropped that line break, so no space was left between them. The fix added an explicit space after the link in `StewardBody.astro`.

After the fix, the sentence read "agents/steward holds the workflows and a README on how they work." The page and its markdown copy both read that way.
