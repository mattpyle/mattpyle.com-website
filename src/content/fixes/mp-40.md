The WebMCP tool describe_site tells agents to call it first for context about the site. It returned seven sections: Home, Writing, Projects, Changelog, Scorecard, Activity and About. The agent at /a2a gave the same seven when asked what sections the site has.

The llms.txt file lists ten pages. The three missing were WebMCP, Steward and Audit, which are the pages about the site's agent work.

The sections mirror the header navigation, and those three pages are not in it. An agent asked whether the site can audit another site found no audit page in either answer.

The site description now carries a separate pages list naming the three, beside the unchanged sections. It appears in the WebMCP index, in describe_site and in the agent's answer. The index now contains the audit page's address.
