The markdown versions of /writing, /projects and the home page listed their cards badly. Each card became one long link that held the date, the title, the description and the reading time. On /writing.md, one line ran to 721 characters and held three links. /projects.md had an 881-character line.

Nothing separated one item from the next, and nothing marked a title. An agent or a person reading these pages wanted one entry per item with the title as the link text. These are the index pages an agent most needs.

The converter split a card into a heading only when the card already held a heading tag. The cards used plain spans for their titles, so every card stayed one link. The fix teaches the converter the card title classes. The HTML pages did not change.

Each card now comes out as its own block. The link text is the title alone, for example "How to implement WebMCP on a website", with the date and description beneath. The Writing, Projects and home pages all follow this pattern.
