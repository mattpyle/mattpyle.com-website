The Projects page says "Hobby projects, not a portfolio". Four machine-readable surfaces said the opposite. The llms.txt file called the site a personal blog and project portfolio. The agents.md file called it a portfolio of small side projects. The agent at /a2a and the site's Agent Skill used the same word.

A recruiter who asked an AI assistant who Matt Pyle is, and what the site is, got the answer from those surfaces. The human pages had been edited to avoid exactly that career framing.

The Projects wording had changed, and the four agent files had not.

All four now describe the site as hobby projects. The word "portfolio" is gone from llms.txt, agents.md and the skill file. The agent still recognises the word when a visitor asks with it.
