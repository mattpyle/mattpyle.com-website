The paragraph under the Rate limits table on the Steward page ran a tool name into the next word. It read "get_auditspends no audit allowance", with no space after `get_audit`. The markdown version of the page had the same joined word.

This let down a developer reading that section to learn what a `get_audit` poll costs them.

In the page source, the tool name ended one line and the next word began the following line. The build dropped that line break, so no space reached the page. The fix adds an explicit space after the tool name in `src/components/steward/StewardBody.astro`. That file feeds both the page and its markdown version.

Both now read "`get_audit` spends no audit allowance", with the space in place.
