The paragraph under the Rate limits table on /steward ran a tool name into the next word. It read "get_auditspends no audit allowance". The markdown copy of the page had the same fault, as `` `get_audit`spends ``.

The sentence is for developers who want to know what a `get_audit` poll costs them. The joined word did not change the fact. It was a reading snag on a page that explains how the site gets details right.

The cause was a line break in `src/components/steward/StewardBody.astro`. The closing `code` tag ended one line, and "spends" began the next. Astro drops that break, so no space reached the page. The fix adds `{' '}` after the closing tag. The same file feeds the page and its markdown copy, so this fixed both.

Both versions of /steward now read "`get_audit` spends no audit allowance", with the space in place.
