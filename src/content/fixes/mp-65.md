The site publishes two discovery documents for its public audit endpoint: /.well-known/mcp-server and /.well-known/ard.json. Both ended their description with "No auth, no account, and nothing is stored."

That was wrong. The endpoint keeps one report per site for each UTC hour and hands it to the next caller who asks about that site. A second call about example.com, a minute after the first, ran no audit. It returned the first call's stored report with the same start time. The endpoint's own tool description already said this.

A developer judging whether to copy the endpoint reads these documents first and quotes their storage claims. The site is careful elsewhere to say what it keeps, so the false line undercut that.

Both documents now say that no caller data is kept. They add that each site's report is kept for its UTC hour and shared with anyone who asks about that site in that hour. The words "nothing is stored" appear in neither.
