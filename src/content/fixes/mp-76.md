The Activity page shows who reads the site. Its first column, headed "bot or agent", marks named bots and agents with a coloured swatch. Every cell in that column held only a swatch hidden from assistive technology.

Across the two tables there were 30 marker cells, and 17 were agent rows. A screen-reader user heard a column header and then 30 empty cells. They could not tell GPTBot from an unknown client or a browser.

The legend's swatch was hidden too, so the legend named the classification with nothing to tie it to. The markdown version of the page already carried the same fact as a Kind column.

Each agent row's marker cell now holds visually hidden text reading "bot or agent", in both tables. Cells for other clients stay empty, as before.
