In the retro homepage, the guest book and the "Email the Webmaster" note refuse empty fields. All three fields reported required as false to a screen reader. Only the name field said "Required" in its hint.

The message hint said only "Up to 280 characters." and the webmaster note only "Up to 500 characters." Submitting either empty gave an error: "Write something so there is an entry to sign." and "Write something first."

A screen reader user tabbing through the fields heard nothing about that rule until the submit failed. The error handling itself was sound, with focus moved to the field.

The name field, the guest book message and the webmaster note now carry aria-required. Both message hints start with "Required.", as the name hint already did.
