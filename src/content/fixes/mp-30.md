The About page has a section headed "Everything here is built in the open". Its first sentence says the code is public. That phrase was plain text.

The section held two links, one to the changelog and one to a project page. Neither went to GitHub. A reader could reach the repository only through the general GitHub profile link under "Say hello", or from the homepage project card.

That left the claim unchecked at the moment a reader was most likely to act on it.

The phrase "The code is public" now links to the repository at github.com/mattpyle/mattpyle.com-website. One click from the sentence reaches the code.
