llms.txt described the homepage as "bio, tagline, recent activity feed". The WebMCP content index and the answer from the site's agent used the same words.

The homepage has no bio. It opens with the name "Matt Pyle" and one line about the site, then shows writing, projects, agent surfaces, the scorecard and the changelog. The bio is on /about. The description dated from the first version of the homepage.

A recruiter's assistant asked to summarise who Matt is would pick the page the map says holds a bio. It would waste a fetch, and could guess a biography from a tagline about the site.

The Home line in llms.txt now reads "name, tagline, and the latest writing, projects, scorecard and changelog." The About line is unchanged.
