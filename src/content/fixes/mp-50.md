The markdown versions of /about, /projects and /scorecard carried a phrase meant for screen readers. The HTML hides "(opens in a new tab)" visually, and a screen reader speaks it after each external link. The conversion to markdown copied it into the link text. It appeared five times in about.md, twice in projects.md and once in scorecard.md.

A markdown link has no tab to open. An agent reading these pages wanted clean link text such as "Temporal Technologies". It got "Temporal Technologies (opens in a new tab)", and it could quote that noise in a summary or a citation.

The converter now drops the hint before it writes the markdown. The HTML pages keep the hint for screen reader users. All three markdown pages now hold no copy of the phrase, and each link reads as its name alone.
