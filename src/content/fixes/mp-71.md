The link at the end of a post read "next" followed by a date. On the WebMCP post it read "next · 18 Jul 2026" and led to the hello-world post, which is older. From hello-world, the next link led to the older accessibility post.

The changelog words the same link differently. Each changelog entry ends with "older" and a date. So the same link meant opposite things on two kinds of page.

The end-of-post link is how a first-time reader reaches a second page. A visitor expecting something newer got something older.

The label now reads "older", as the changelog does. A click is now a choice and not a guess.
