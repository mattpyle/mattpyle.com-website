The About page has a paragraph headed "This site is an experiment". It lists what the site implements for agents: llms.txt, agents.md, a WebMCP surface, markdown at every URL and a scorecard. The page never mentioned "A2A", in its HTML or in `/about.md`. It said nothing about the MCP server at `/mcp` either.

The site does run both. The Projects page names server routes for `/mcp` and `/a2a`. llms.txt describes the A2A endpoint and its four methods. The sentence on About was written before either endpoint existed.

This let down a peer in Matt's field. Such a reader skims About to judge whether the site does something unusual. They read the list as the answer. The most unusual items, an agent that answers and audits in conversation and an MCP server, were missing.

The fix added two items to the list in `src/components/about/AboutBody.astro`: "an MCP server at /mcp" and "an A2A agent at /a2a that answers and audits in conversation". The About page on production now names both.
