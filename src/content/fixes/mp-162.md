The About page has a paragraph headed "This site is an experiment". It lists what the site implements for agents: llms.txt, agents.md, a WebMCP surface, markdown at every URL and a scorecard. The page did not contain "A2A" once, and it never mentioned `/mcp`.

A peer in Matt's field reads this list to judge what the site does that others do not. The list left out the site's two largest agent surfaces. These are an A2A agent at `/a2a` that answers and audits in conversation, and an MCP server at `/mcp`. The Projects page names both routes, and llms.txt describes the A2A endpoint. A reader of the About page could not learn of either.

The sentence was hand-written before either endpoint existed. The fix adds both to the same list, one short item each.

The About page on production now names both, and contains "A2A" once.
