The site calls its code public. Three pages send readers to the same repository: the project page for the auditor, the About page and the Projects page. They invite developers to look at it, and some to copy it.

The repository had no licence. GitHub's API returned a null licence, the licence page returned 404, and no file or package setting named one. Under default copyright, nobody may reproduce or build on code without a licence.

A developer who decided a tool handler or an audit check was worth reusing could read the code but not use it.

The repository now has an MIT licence file at its root. A README section says the writing under the content folder is not covered and stays all rights reserved. No page text changed.
